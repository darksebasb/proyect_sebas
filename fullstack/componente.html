¿Que es un Componente?

Es un bloque de código independiente que combina y puede ser utilizado n cantidad de veces, sin la necesidad de volver a crear el código desde cero.

  • HTML (estructura)
  • CSS (estilos)
  • JavaScript (comportamiento)

¿Para qué sirve un Componente?

Proposito Explicación sencilla
Reutilizar código Escribes el componente una vez y lo usas en 10, 50 o 100 páginas.
Mantener el orden Cada componente se encarga de una sola cosa. Si falla el menú, sabes exactamente dónde buscar.
Trabajar en equipo Un desarrollador puede crear el botón, otro la tarjeta, y otro el footer, sin pisarse.
Actualizar fácilmente Cambias el componente en un solo archivo y se actualiza en todas las páginas donde se use.

¿Cuándo se usa un Componente?

Elemento ¿Por qué?
Botón Tienes el mismo estilo de botón en "Enviar", "Guardar", "Comprar".
Tarjetas de productos Muestras 20 productos con la misma estructura (imagen, título, precio, botón).
Menús de navegación Aparece en todas las páginas. Si lo cambias en un lugar, debe cambiar en todos.
Footer Contiene información de contacto, redes sociales y derechos de autor. Se repite en todas las páginas.
Modal / Pop-up El mismo cuadro de diálogo se abre desde diferentes botones.
Formulario de contacto Se usa en la página de contacto y también en un pop-up lateral.
