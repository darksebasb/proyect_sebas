Glosario

API: es un conjunto de reglas y protocolos que permite que diferentes aplicaciones se comuniquen entre sí, facilitando el intercambio de datos y funcionalidades.

CSSEs un lenguaje de diseño usado para darle la apariencia visual a una página web

Base de datos: es un sistema organizado para almacenar, gestionar y recuperar información de manera estructurada.

Backend: es la parte de una aplicación o sitio web que se encarga de procesar la lógica, manejar la base de datos y realizar operaciones detrás de escena, generalmente no visible para los usuarios.

Frontend: es la parte de una aplicación o sitio web que interactúa directamente con los usuarios, incluyendo la interfaz de usuario y la experiencia visual.

Endpoint: es una URL específica en un servidor que permite a los clientes (como navegadores web o aplicaciones móviles) acceder a recursos o servicios, generalmente a través de solicitudes HTTP.

HTTP: es un protocolo de comunicación utilizado en la web para transferir datos entre clientes y servidores, permitiendo la carga de páginas web y la interacción con servicios en línea.

JSON: es un formato de datos ligero y fácil de leer que se utiliza para intercambiar información entre un cliente y un servidor, especialmente en aplicaciones web.

REST: es un estilo de arSASAquitectura para diseñar servicios web que utiliza métodos HTTP y recursos identificados por URLs, promoviendo la simplicidad y escalabilidad en la comunicación entre sistemas.

Servidor: es una computadora o sistema que proporciona servicios, recursos o datos a otros dispositivos (clientes) a través de una red, como la web.

URL: es la dirección única que se utiliza para localizar y acceder a recursos en la web, como páginas web, imágenes o archivos.

Variable: es un espacio de almacenamiento en la memoria de un programa que puede contener diferentes valores a lo largo del tiempo, permitiendo que los datos sean manipulados y utilizados en el código.

Padding: es el espacio interno entre el contenido de un elemento (como un texto o una imagen) y su borde evitando que los elementos queden pegados a los bordes.

Request: mensaje que un cliente (como tu navegador web o una aplicación móvil) envía a un servidor para pedir información, enviar datos o realizar una acción.
